PandaLead — comandos de despliegue (GitHub Pages, igual que miCartera)
========================================================================

Repo: https://github.com/goldenpandaz/PandaLead
Método: angular-cli-ghpages — compila y pushea el resultado a la rama
"gh-pages" del repo, que GitHub sirve como sitio estático. Mismo mecanismo
que usa miCartera (Kontrol-Cash) — no es Firebase Hosting.

--------------------------------------------------------
0) UNA SOLA VEZ — instalar la dependencia nueva
--------------------------------------------------------
npm install

(Ya está agregada en package.json — esto solo la baja a node_modules. Si ya
corriste npm install después de que se agregó, no hace falta de nuevo.)

--------------------------------------------------------
1) CADA VEZ que quieras desplegar
--------------------------------------------------------
npm run deploy:pages

Este único comando hace 3 cosas en cadena:
  1. Compila la app con --base-href=/PandaLead/ (necesario: GitHub Pages
     sirve el sitio desde ese subpath, no desde la raíz del dominio).
  2. Copia index.html a 404.html — truco necesario para que andar bien las
     rutas de Angular (/dashboard, /settings, etc.) al recargar la página o
     entrar directo por URL, porque GitHub Pages no tiene rewrites como
     Firebase — sin esto, F5 en cualquier ruta que no sea la home tira 404.
  3. Pushea dist/pandalead/browser a la rama gh-pages del repo.

--------------------------------------------------------
2) URL donde queda publicada la app
--------------------------------------------------------
https://goldenpandaz.github.io/PandaLead/

(Puede tardar 1-2 minutos en propagarse la primera vez que se crea la rama
 gh-pages. Verificalo también en GitHub → Settings → Pages del repo, que
 diga "Your site is live at...".)

--------------------------------------------------------
Requisito de Node
--------------------------------------------------------
Angular 22 necesita Node 22.22.3+ / 24.15.0+ / 26+. Si `npm run` tira error
de versión, en PowerShell:

  nvm list
  nvm use 24.19.0

--------------------------------------------------------
Firebase Hosting (queda configurado pero SIN USAR)
--------------------------------------------------------
firebase.json y .firebaserc siguen en el repo por si en algún momento se
quiere usar Firebase Hosting en vez de / además de GitHub Pages, pero el
despliegue real de PandaLead es por GitHub Pages (arriba). No hace falta
tocar esos archivos para nada de lo de este documento.
